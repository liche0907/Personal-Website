# liche0907.github.io

Personal website of Che Li, built on the [academicpages](https://github.com/academicpages/academicpages.github.io) Jekyll template and served by GitHub Pages.

Content lives in `_pages/` (about, research, industry, teaching, cv). The CV PDF is `files/Che_Li_CV.pdf`. Sidebar and site settings are in `_config.yml`; the menu is in `_data/navigation.yml`.
